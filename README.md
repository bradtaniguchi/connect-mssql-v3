# Connect-MSSQL-V3

Third iteration of the same overall project, with a re-write focused around the tooling, to help support the extension over time.

## connect-mssql-v3? What about V2 or V1?

V2 was created as a re-write of V1, V3 (this one) is more or less a maintenance rewrite of V2.

Consider V3 to be a **slightly** breaking change version of V2, but overall is the same.

A majority of the changes in this repo are dedicated to best practices, improving tooling and testing.
